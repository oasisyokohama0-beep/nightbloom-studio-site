2. カスタムHTMLブロックの中身を `wordpress-custom-html.html` の内容で**丸ごと置き換える**。
3. 下書きのまま「プレビュー」で確認 → 問題なければ「設定 → 表示設定 → ホームページ」を新ページに切り替える。

## 既存の「追加CSS」で注意が必要な箇所

外観 → カスタマイズ → 追加CSS に、次のルールがあります。

```css
[class*="menu"],
[class*="drawer"],
[class*="search"] { display: none !important; }
```

新デザインのクラス名はすべて `nx-` で始まり、`menu` / `drawer` / `search` を含みません（セクション ID の `#menu` はクラスではないので対象外）。
今後ブロックを編集するときも、この3語を含む**クラス名**は使わないでください。

同じ追加CSSの `body { background: #0b0b0d }` は、読み込み中のちらつき防止のため、切り替え後に以下へ変更を推奨します。

```css
:root { --bg: #FFFFFF; }
body  { background: #FFFFFF; }
```
